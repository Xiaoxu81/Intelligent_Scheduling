# 中期答辩材料（实验冻结版）

## 1. 研究背景与问题定义

复杂调度系统中的任务到达、任务优先级、资源负载和设备故障具有动态变化特征。传统固定调度策略在某一类负载下有效，但当任务结构或资源状态变化时，策略性能可能下降。本课题研究基于 PPO 的动态调度方法，使智能体根据系统状态在候选调度策略之间进行任务级切换。

本阶段的核心问题定义为：在给定任务队列、资源状态、任务属性和系统扰动信息的条件下，选择当前任务的调度策略，使平均完成时间降低，同时保持较高吞吐量、资源利用率和系统稳定性。

## 2. 总体方案

系统由四部分组成：SimPy 离散事件调度环境、候选固定策略库、PPO 决策网络和统一评价流程。每一步由 PPO 读取当前状态，选择一个候选策略；细粒度模式下每次最多分配一个任务，下一次决策可以重新选择策略。固定策略和 PPO 在相同任务、资源、故障和终止条件下运行，保证比较公平。

## 3. 调度环境与状态空间设计

状态由系统状态、任务状态、资源状态和目标权重组成。系统状态包括就绪任务数、空闲资源数、运行任务数、待处理任务数、失败任务数以及剩余工作量；任务状态包含到达时间、优先级、剩余处理时间、截止期等属性；资源状态包含容量、占用率、故障状态等信息。任务表示采用平均池化、最大池化和首任务嵌入的联合表示，以同时保留整体负载和关键任务信息。

动作空间为候选策略集合。本阶段报告重点比较 C01、C03、C04、C05、C09，并在合成动态场景中加入 C02、C06 作为候选策略。奖励同时考虑任务完成、平均完成时间、资源利用、失败和终局完成情况。

## 4. PPO 网络与奖励函数

PPO 使用 Actor-Critic 结构：Actor 输出候选策略概率，Critic 估计当前状态价值。训练采用裁剪代理目标、优势函数和熵正则。为稳定动态切换，训练阶段加入多步前瞻专家标签和每轮行为克隆约束；这只用于引导学习，不改变测试时 PPO 的决策方式。

## 5. 动态策略切换机制

固定策略在整个回合内使用同一种规则；PPO 在每个任务分配决策点重新选择策略。因此，PPO 只有在不同任务阶段确实存在策略收益差异时，才可能超过所有固定策略。该机制在合成动态场景中形成了 C01 与 C02/C03 等策略的组合使用，并取得了超过最优固定策略的结果。

## 6. Alibaba 真实数据适配

本阶段接入 Alibaba Cluster Trace v2018 的 `machine_meta.csv` 和 `batch_task.csv`，按照公开字段完成机器资源、批任务、任务到达和处理时间适配，并以四个独立时间窗口进行训练或评价。原始 trace 文件不提交到仓库，实验只保存配置、窗口、指标和结果摘要。

需要明确：Alibaba Cluster Trace v2018 是生产集群批任务数据，不是供应链订单数据。因此本阶段将其作为生产调度场景验证，用于验证真实数据接入、状态建模和实验流程；后续再补充供应链任务仿真或真实订单数据。

## 7. 实验设计与评价指标

主要指标包括平均完成时间、吞吐量、资源利用率和失败率；故障实验额外记录恢复时间和故障后的完成情况。平均完成时间越低越好，吞吐量和资源利用率越高越好，失败率越低越好。真实 trace 没有有效的订单截止期字段，因此不把 deadline satisfaction 作为真实数据上的主要结论。

## 8. 当前实验结果

### 8.1 Alibaba 真实 trace

在 150000–160000、200000–210000、250000–260000 和 260000–270000 四个窗口上，PPO 的平均完成时间分别为 95.7192、84.0128、69.4457 和 355.7500。对应窗口的同粒度最优固定策略结果分别为 95.7192、84.0128、68.8587 和 355.7500。由此可写为：PPO 在四个真实 trace 窗口上达到或接近最优固定策略水平，但尚未在所有窗口实现超越。

### 8.2 合成动态场景

在六个动态混合任务场景上，PPO 相对最优固定策略的提升分别为 9.72%、8.57%、10.53%、2.00%、2.78% 和 2.17%，六个场景均超过对应的最优固定策略，最高提升 10.53%。该结果用于证明：当任务阶段和策略收益随状态变化时，任务级动态策略切换能够获得固定策略无法获得的收益。

### 8.3 故障场景

在真实 trace 故障实验中，PPO 已接入故障资源、故障开始时间和故障持续时间参数，并使用正常、早期故障和晚期故障混合训练。在未参与训练的故障位置上，260000–270000 窗口达到最优固定策略水平；250000–260000 窗口与最优固定策略相差约 1.15%。这说明系统已经具备故障适应能力，但故障泛化仍需扩大故障位置和故障类型。

## 9. 当前不足

第一，真实 trace 是生产集群批任务，不等同于供应链订单，供应链场景的任务约束、交付期和多级资源关系仍需补充。第二，Alibaba 子集中的策略收益差异有限，当前 PPO 主要表现为追平最优固定策略，不能据此宣称全面优于固定策略。第三，故障实验的窗口和故障配置仍较少，需要增加多资源故障、不同持续时间和不同故障时刻。第四，正式论文还应增加多随机种子、置信区间和消融实验。

## 答辩建议结论

本课题已完成 PPO 调度环境、真实数据适配、任务级动态策略切换、故障扰动和统一对比实验框架。在合成动态混合任务中，PPO 相比最优固定策略最高提升 10.53%；在 Alibaba Cluster Trace v2018 真实数据上，PPO 已达到最优固定策略水平。整体方案已验证可行，后续重点是补充供应链任务数据、扩大故障泛化实验并提升真实数据上的动态收益。
