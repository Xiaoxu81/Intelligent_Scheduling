# 中期考核报告扩充设计

## 目标

将现有7页中期考核报告扩充至15—16页。扩充后的内容应以开题报告的完整论证结构为基础，但必须体现中期阶段的研究调整、已完成工作、当前不足和后续验证安排，避免简单复制或虚构实验结论。

## 内容原则

1. 研究背景、研究意义和国内外研究现状从开题报告中提炼并改写，统一使用当前研究口径：面向任务需求并受资源可行性约束的候选调度策略评价与智能选择。
2. 不再沿用“解决数据孤岛”作为研究目的，不把研究限定为单纯策略选择，也不夸大为已经实现完整的任务—资源—策略联合优化。
3. 中期内容必须明确区分“已完成”“进行中”和“计划开展”，不得将尚未完成的资源能力匹配、示范预训练、反馈优化和系统实验写成既有成果。
4. 不编造论文发表、实验数值、软件著作权授权、导师意见或专家结论。
5. 课程学分沿用开题报告中已有的计划28学分、完成21学分；开题报告学分栏保持空白。

## 第二部分结构与篇幅

第二部分“硕士研究生论文工作阶段性总结”扩展为约11—12页，整份文档预计15—16页。

1. 研究背景：约1页。说明产业链协同中的跨企业任务、共享资源和动态运行环境，并引出产业链互联操作系统及调度模块。
2. 研究意义：约1页。分别说明差异化任务调度、动态环境适应、产业链协同运行效能三个层面的意义。
3. 国内外研究现状：约2页。分为多目标调度评价和智能策略选择两部分；复用开题报告中的两张文献对比表，但压缩表述并增加与当前研究问题的差距分析。
4. 研究目标与内容调整：约1页。交代从开题阶段的任务目标驱动策略选择，细化为任务需求、资源可行性和运行状态共同约束的候选策略评价与选择。
5. 研究内容与关键问题：约1页。对应问题一和问题二，解释输入S、T、R、wT、候选策略集合及示范—反馈学习闭环。
6. 技术路线与方案：约1页。按仿真环境、候选策略库、评估模型、示范样本、PPO模型、反馈优化的链路展开。
7. 已完成工作与阶段成果：约2页。保留阶段成果表，详细说明任务与资源建模、SimPy环境、12种策略、Gym接口、PPO原型和核心流程验证。
8. 当前不足与改进方向：约1页。说明任务需求表示、资源能力约束、候选策略评价和示范—反馈闭环的不足。
9. 实验设计与评价指标：约1页。说明对照方法、消融实验、核心指标、动态场景和泛化测试，不填写尚未产生的实验结果。
10. 论文及其他成果情况：约0.5页。说明当前以原型与材料积累为主，暂无材料可证明已正式发表论文。
11. 后续研究计划与阶段总结：约1页。保留时间计划表，衔接论文初稿、实验分析、系统演示和毕业答辩。

## 表格设计

保留并完善四张表：

1. 培养计划完成情况表：沿用模板。
2. 国内外研究现状对比表：两张，分别对应多目标调度评价和智能调度策略选择。
3. 中期阶段成果表：区分工作内容、阶段成果与完成状态。
4. 后续工作计划表：列出时间、主要任务和预期产出。

表格使用模板的黑色边框和宋体，表头采用浅蓝底色；不固定行高，避免文字截断。跨页表格重复表头，单行不得跨页拆分。

## 版式与验收

1. 保持原始封面、填表说明、导师意见和专家考核栏的版式。
2. 正文使用宋体10.5磅，小标题使用宋体11磅加粗，行距约1.2倍。
3. 最终页数必须不少于15页，目标为15—16页。
4. 逐页渲染检查，要求无文字溢出、表格断裂、孤立标题、重叠或乱码。
5. 最终覆盖用户指定的 `D:\Intelligent_Scheduling\中期答辩\硕士研究生论文中期考核报告（2024） - 副本.doc`，并保留原始备份和可编辑DOCX版本。
